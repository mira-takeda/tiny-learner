05 / How tiny?

Small enough for
a tiny robot's controller.

Four skill networks and their selector: 7,944 parameters. Stored at 32 bits each, their weights take just 31.8 kB.

31.8 kB of weights.Small enough to fit within the memory of an ESP32-class controller, the kind used in small connected devices and robots.
A possible destination.A hardware port would still need code, working memory and sensor integration. On-device operation has not yet been tested.

06 / Research

Can a tiny learner combine
what it already knows?

Can a tiny neural system learn skills separately, retain them as new skills arrive, and recombine them to solve situations never trained together? Controlled comparisons test whether learned modular routing helps beyond a similarly sized monolithic network and simpler routing controls.
